# Module: :core:ui

The `:core:ui` module contains shared UI components, theme definitions, and resources used across all feature modules.

## Responsibilities

- **Theme**: Defining the application's color palette, typography, and shapes using Material 3.
- **Common Components**: Reusable UI elements like custom buttons, loading indicators, and error views.
- **Resources**: Shared string resources, icons, and animations.

## Key Components

- `theme/Color.kt`: Color definitions for light and dark themes.
- `theme/Type.kt`: Typography settings.
- `theme/Theme.kt`: The main Composable theme wrapper.
